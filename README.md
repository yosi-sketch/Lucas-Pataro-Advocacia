# Lucas & Pataro Advocacia e Consultoria Jurídica

Site institucional de alto padrão do escritório **Lucas & Pataro Advocacia e Consultoria Jurídica**, liderado pelos advogados **Dra. Clarissa Pataro** e **Dr. Diego Lucas**, sediado em Ponte Nova - MG, com atendimento presencial e on-line em todo o Brasil.

## Desenvolvimento

Instale as dependências com `npm install` e inicie o ambiente local com `npm run dev`.

Abra [http://localhost:3000](http://localhost:3000) para visualizar o site.

## Tecnologias

- Next.js 16 com App Router e Turbopack
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide React
